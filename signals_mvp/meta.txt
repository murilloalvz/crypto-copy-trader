#
# Formato (uma linha por grupo):
#     ROTULO: palavra1, palavra2, palavra3
# Linha sem ":" vira um grupo com o proprio nome da palavra.
# Linhas que comecam com # sao comentario. Maiuscula/minuscula e acento nao importam.
#
# O casamento e feito no NOME, no TICKER e na DESCRICAO do token. Palavra curta
# (menos de 4 letras) so casa como palavra inteira; palavra maior tambem casa
# dentro de outra ("agent" casa "AIAgent").
#
# Cada vez que voce muda este arquivo o bot calcula uma nova `versao_meta`
# (hash do conteudo, sem contar comentarios) e grava em cada linha do sinais.csv.
