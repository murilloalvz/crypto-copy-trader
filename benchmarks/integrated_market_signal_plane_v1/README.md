# Integrated Market Signal Plane Replay v1

Purpose: validate the missing composition boundary after two prior results:

- `PASS_CARBON_DECODER_PARITY_V1` — Carbon Pump.fun/PumpSwap event semantics matched 150/150 target events exactly.
- `ADAPT_CARBON_RUNTIME_BOUNDARY` — stock Carbon processors must stay constant-time because slow inline work creates global HOL.

This benchmark does **not** repeat raw transaction decoder parity. It validates the next architectural layer:

```text
canonical event
    -> strict adapter
    -> bounded memory-first Radar kernel
    -> bounded async research handoff
```

The frozen Market Opportunity Radar remains unchanged.

## Frozen protocol

- synthetic canonical trace seed: `68`
- default records: `10,000` trades plus lifecycle events generated by the existing commodity signal-plane v0 trace generator
- representative rate: `5,000 events/s`
- headroom rate: `7,500 events/s` (`1.5x`)
- downstream research buffer: `1,024`
- slow downstream work: `5 ms` every 100th event
- burst overload: all research arrivals at time zero

## Required checks

`PASS_INTEGRATED_MARKET_SIGNAL_PLANE_V1` requires:

1. canonical adapter exact round-trip for every record;
2. frozen Radar trigger/features parity = 100%;
3. no kernel backlog at 5k events/s;
4. no kernel backlog at 7.5k events/s;
5. zero research handoff drops at 5k;
6. zero research handoff drops at 7.5k;
7. burst accounting is exact;
8. burst worker completion equals accepted handoffs;
9. burst overload produces explicit drops instead of silent loss.

If semantic parity fails, do not optimize around it.
If capacity fails with semantics intact, classify `OPTIMIZE_OR_PARTITION_MEMORY_KERNEL`.
If only downstream accounting/isolation fails, classify `ADAPT_RESEARCH_HANDOFF_POLICY`.

## Why deterministic queue simulation

The kernel service times are measured from the real Python kernel on the replay. Queue pressure is then evaluated with deterministic single-worker timing. This avoids CI scheduler noise while preserving measured service cost and explicit bounded-overload accounting.

The Carbon runtime itself was already exercised with real Tokio bounded MPSC in `carbon_runtime_replay_v1`; this experiment composes the next boundary rather than duplicating that test.
